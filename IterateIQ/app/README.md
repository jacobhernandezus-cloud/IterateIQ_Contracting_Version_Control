## First-time setup

### 1. Install dependencies

```bash
cd "IterateIQ/app"
npm install
```

### 2. Set up Supabase (local)

```bash
# from IterateIQ/ root, not app/
cd ".."

# Install the Supabase CLI if you don't have it
brew install supabase/tap/supabase

# Start local Supabase (Postgres, Auth, Storage in Docker)
supabase start

# Apply migrations
supabase db reset

# Create the 6 H9 auth users (matches UUIDs in seed.sql)
SUPABASE_URL=http://127.0.0.1:54321 \
  SERVICE_ROLE_KEY="$(supabase status -o json | jq -r .service_role_key)" \
  ./supabase/scripts/seed_auth_users.sh

# Apply seed data
psql "postgresql://postgres:postgres@127.0.0.1:54322/postgres" -f supabase/seed.sql
```

### 3. Configure the app

```bash
cd app/
cp .env.example .env.local
# Fill in the URL + anon key printed by `supabase status`
```

### 4. Run the dev server

```bash
npm run dev
```

Open http://localhost:5173 — you should see the Lane A smoke-test login page,
then a token-verification dashboard at /dashboard.

## Daily workflow

```bash
# Start the dev server (port 5173, strict)
npm run dev

# Type-check
npm run typecheck

# Lint
npm run lint

# Format
npm run format

# Unit tests (Vitest)
npm test

# E2E tests (Playwright — Lane G)
npm run e2e
```

## Generating updated TypeScript types after schema changes

```bash
cd ".."
supabase gen types typescript --local > app/src/lib/database.types.ts
```

## Deployment

`iterateiq-h9.netlify.app` currently serves the static MVP HTML. The cutover to
the React build happens in Lane G (test + ship). Until then, deployment is
local-only — partners keep using the partner demo URL.
