# IterateIQ — Contract Management Platform

**H9 Partners** | Version 2.0 | March 2026

IterateIQ is a contract management platform built for H9 Partners to manage freelance and contract engagements. Contractors track projects, phases, earnings, and feedback. Managers post opportunities, set pricing/timelines, and monitor progress.

## Repository Contents

| File | Description |
|------|-------------|
| `IterateIQ_MVP.html` | Interactive HTML prototype (fully functional demo) |
| `IterateIQ_MVP.jsx` | React JSX version of the full application |
| `IterateIQ_ContractWidget.jsx` | Standalone contract builder widget |
| `IterateIQ - Product Specification v2.docx` | Production spec & architecture document (v2.0) |
| `IterateIQ - Product Specification.docx` | Original MVP specification (v1.0) |
| `IterateIQ_UX_Research_Plan.docx` | UX research plan |

## Tech Stack (Production — v2.0)

- **Frontend**: React 18 + Vite + TypeScript
- **Backend**: Supabase (PostgreSQL + Auth + Storage + RLS)
- **Deployment**: Netlify with GitHub CI/CD
- **Design System**: H9 Design System (custom tokens)

## Getting Started

Open `IterateIQ_MVP.html` in a browser to explore the interactive prototype.
